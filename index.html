Como jogar

✅ PEGUE (brilham em verde): 🎾 bolas de tênis, 🏆 troféus, 🪙 fichas e 💚 vida extra.

❌ FUJA do resto. Cada perigo tem uma placa vermelha dizendo o que fazer:

PULE ▲ · ABAIXE ▼ · DESVIE ◀▶

  • Deslize para os lados para trocar de faixa.
  • Deslize para cima (ou toque na tela) para pular coisas baixas.
  • Deslize para baixo para abaixar de convites voando.
  • Gente e paredões no caminho: troque de faixa.
  • Pegue bolas de tênis, troféus e fichas.
  • Na última fase, aperte RAQUETADA para devolver bolas gigantes.
  • No computador: setas, espaço para pular, X para raquetada, P para pausar.

Tudo aqui é brincadeira e fictício. As fichas são virtuais: não valem dinheiro.
